### Flashcard App - "TargetTester"

A language learning web app made using TypeScript, React and Astro.

## How does it work?

A user will be able to choose their target language, and then generate flashcards at the desired CEFR level to test their knowledge.

There will be a correct answer and a randomised incorrect answer for a user to choose from on the flashcard.

When a user correctly translates a flashcard 3x, it moves to their on-target pile.

When a user consistently incorrectly translates a flashcard, it moves to their off-target pile.

A user can generate new flashcards by clicking the New Target words pile (new words appear for every new addition to the on-target pile)
